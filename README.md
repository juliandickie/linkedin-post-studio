# LinkedIn Post Studio

> ⚠️ **Under construction — v1.0 in progress.** Final README lands in Phase 13 of the implementation plan.

Profile-driven LinkedIn content generation for Claude Code, Claude Desktop, and Cowork.

## Installation (preview)

See [spec §9](../specs/2026-04-19-linkedin-post-studio-design.md) for full install instructions. Once v1.0 ships:

```bash
# Full plugin (Claude Code / Desktop code mode / Cowork)
cd ~/.claude/plugins/
git clone https://github.com/juliandickie/linkedin-post-studio.git

# Skill only (Claude Web / Desktop chat mode)
cp -r linkedin-post-studio/skills/linkedin-post-studio ~/.claude/skills/
```
